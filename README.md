# home-guide

## Ảnh theo ngôn ngữ

Trang mặc định dùng EN với các ảnh hiện tại trong `assets/`.
Khi chọn VN, tất cả các tab hiện dùng chung ảnh `assets/Welcome.jpg`.
Sau này có thể đổi `data-src-vi` của từng ảnh trong `index.html` sang bộ ảnh tiếng Việt.
Mục Explore hiện dùng chung ảnh Welcome như bố cục ban đầu.
